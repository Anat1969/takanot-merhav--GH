# תקנות במרחב

מדריך תלת־ממדי לתוספת השנייה לתקנות התכנון והבנייה (בקשה להיתר, תנאיו ואגרות), התש״ל-1970: תוכן עניינים, חיפוש בעברית, ושבע המחשות שבהן כל מידה במודל מקושרת לערך בנוסח.

**כתובת:** https://anat1969.github.io/takanot-merhav--GH/

## מצב

- 61 סעיפים בתוכן העניינים, 28 עם תמצית, 21 סצנות.
- כל 37 הערכים מסומנים ״לאימות״. הם לא נבדקו מול הנוסח הרשמי, ואין להשתמש בהם לפני בדיקה.
- כדי לסמן ערך כמאומת: ב־`data/takanot.json` משנים `verified` ל־`true` וממלאים `source` (מי בדק, מתי, ומול איזה נוסח). הבנייה נכשלת על ערך מאומת בלי מקור.
- לבדיקה: ״ספר תקנות התכן״ של מינהל התכנון מחליף בהדרגה חלקים מהתוספת השנייה. יש לוודא לכל סעיף איזה נוסח בתוקף.
